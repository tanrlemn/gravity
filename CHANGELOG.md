# Changelog

## v0.1.0 — 2026-10-09

First public release.

- `SKILL.md`: the method as an Agent Skill — bootstrap, spec, write-back, standing rules.
- `templates/`: job, domain, invariants, boundaries, grammar, spec.
- `adapters/`: pointer files for AGENTS.md, Claude Code, Gemini CLI, GitHub Copilot and Cursor, each under ten lines.
- `bin/gravity-init`: optional POSIX sh bootstrap.
- `docs/method.md`: the method explained, with a worked example from a project in use since 2026-09-22.
- `gravity/`: the kit's own gravity layer.
- No `examples/` yet: a filled, lived-in gravity layer is wanted and tracked as an issue.
