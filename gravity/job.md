# Job

**Who is in pain:** someone whose AI-built codebase drifts — a second name for a concept that had one, logic in whatever file was open, every screen handling errors its own way — and who cannot point at the thing above the features that should have caught it.

**What they do today instead:** long instructions files that get skimmed, folders of prompts, re-explaining the project at the top of every session, and reading diffs for the drift after it lands.

**What "solved" looks like:** five short files in `/gravity/` that every spec is checked against and that every shipped change writes back to, with the method short enough to install in any assistant in five minutes.

**What would make them stop using this:** the method needing a particular tool to work, or the templates growing past a page each.

---
*Tiebreaker: when a change would make the kit more capable but less portable or longer, it does not ship. The method is five files and a habit; the kit is the smallest thing that carries them.*

*Written 2026-10-09 at the kit's first commit.*
